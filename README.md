 3D Design Hub

3D Design Hub is a web application built to explore and interact with 3D models directly in the browser. I built this project to learn more about Three.js and React Three Fiber while creating an interactive 3D experience.

Features

- View 3D models in the browser
- Rotate, zoom and move around the scene
- Interactive camera controls
- Responsive UI
- Fast rendering using Three.js

Built With

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- React Three Drei
- Tailwind CSS

Getting Started

Clone the repository

```bash
git clone https://github.com/narasimha77-jpg/3d-design-hub.git
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

Why I Built This

## Why I Built This

I wanted to understand how 3D graphics work on the web and gain hands-on experience with Three.js and React Three Fiber. Through this project, I learned how to render and interact with 3D objects, manage scenes, implement camera controls, and build immersive user experiences. My goal was to explore how interactive 3D visualization can make it easier for architects and designers to present and communicate their ideas.
